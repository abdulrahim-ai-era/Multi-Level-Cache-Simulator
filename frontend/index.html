About CACHEFLOW & Architecture

University Data Structures and Algorithms semester project demonstration.

DSA Core Foundations

CACHEFLOW demonstrates modern cache design using two foundational data structures working in tandem to achieve O(1) amortized time complexity for both lookup and eviction:

  • Custom Doubly Linked List: Provides O(1) removal, insertion at Head (MRU), and eviction from Tail (LRU) without shifting memory arrays.
  • Hash Map (std::unordered_map): Maps memory addresses to linked list node pointers, enabling constant-time O(1) cache line lookup.
  • Cascading Promotion & Demotion: Exclusive hierarchy invariant ensures that an entry promoted from L2 to L1 displaces L1's LRU line, safely demoting it back to L2.
